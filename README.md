# BowLogger

A bow-mounted motion logger for archery training: a Seeed XIAO nRF52840 Sense taped to the riser records yaw, pitch and cant at 833 Hz around each shot and sends it to a phone over Bluetooth.

- **App (open in Bluefy on iPhone, Chrome on Android/desktop):** https://ikikawa.github.io/bowlogger/
- **Firmware:** `firmware/BowLogger.uf2` — double-tap the board's reset button and drag this onto the `XIAO-SENSE` drive. Source in `firmware/BowLogger.ino`.
